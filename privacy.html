Политика конфиденциальности

Настоящая Политика конфиденциальности описывает обработку информации при посещении сайта dokkino.com.

1. Данные, которые сайт запрашивает сейчас

В текущей версии сайта dokkino.com нет регистрации пользователей, личных кабинетов, форм оплаты или форм, через которые посетитель намеренно передаёт имя, адрес электронной почты или платёжные данные непосредственно владельцу сайта.

2. Языковая настройка

Сайт использует локальное хранилище браузера (localStorage), чтобы запомнить выбранный язык интерфейса — русский или английский. Эта настройка хранится в браузере пользователя и используется для удобства просмотра сайта.

3. Технические данные и хостинг

Сайт размещён с использованием GitHub Pages. Поставщик инфраструктуры может автоматически обрабатывать техническую информацию, связанную с обращениями к сайту, например IP-адрес, тип браузера, дату и время запроса и другие стандартные технические данные, в соответствии со своей политикой конфиденциальности.

4. Сторонние сайты и сервисы

dokkino.com содержит ссылки на сторонние сайты и сервисы, включая YouTube и музыкальные платформы. После перехода по внешней ссылке обработка данных регулируется условиями и политикой конфиденциальности соответствующего стороннего сервиса.

5. Платежи и поддержка проекта

В настоящее время dokkino.com не принимает платежи непосредственно на сайте. Если в будущем будет подключён сторонний сервис для добровольной поддержки проекта, настоящая Политика будет обновлена с учётом соответствующего способа обработки данных.

6. Изменения Политики

Настоящая Политика может обновляться при добавлении новых функций сайта, аналитики, форм обратной связи, платёжных сервисов или других инструментов, связанных с обработкой данных.

7. Контакт

По вопросам, связанным с конфиденциальностью и работой сайта, можно связаться с нами через официальный контакт, указанный на сайте или на официальных страницах проекта.

Privacy Policy

This Privacy Policy describes the handling of information when you visit dokkino.com.

1. Information the website currently asks you to provide

The current version of dokkino.com does not include user registration, user accounts, payment forms, or forms through which a visitor intentionally provides a name, email address or payment information directly to the website owner.

2. Language preference

The website uses browser local storage (localStorage) to remember the selected interface language — Russian or English. This preference is stored in the user's browser and is used to improve the browsing experience.

3. Technical data and hosting

The website is hosted using GitHub Pages. The infrastructure provider may automatically process technical information associated with requests to the website, such as an IP address, browser type, request date and time and other standard technical data, in accordance with its own privacy policy.

4. Third-party websites and services

dokkino.com contains links to third-party websites and services, including YouTube and music platforms. Once you follow an external link, data processing is governed by the terms and privacy policy of the relevant third-party service.

5. Payments and project support

dokkino.com does not currently accept payments directly on the website. If a third-party service for voluntary project support is added in the future, this Policy will be updated to reflect the relevant data-processing arrangements.

6. Changes to this Policy

This Policy may be updated when new website features, analytics, contact forms, payment services or other tools involving data processing are added.

7. Contact

For questions relating to privacy or the operation of the website, please contact us through an official contact method listed on the website or on the project's official pages.
