Политика конфиденциальности

Эта Политика описывает обработку информации при посещении сайта dokkino.com.

1. Какие данные сайт запрашивает сейчас

В текущей версии сайта dokkino.com нет регистрации пользователей, личных кабинетов, форм оплаты или форм, через которые посетитель намеренно передаёт имя, адрес электронной почты или платёжные данные непосредственно владельцу сайта.

2. Языковая настройка

Сайт использует локальное хранилище браузера (localStorage), чтобы запомнить выбранный язык интерфейса — русский или английский. Эта настройка хранится в браузере пользователя и используется для удобства просмотра сайта.

3. Технические данные и хостинг

Сайт размещён с использованием GitHub Pages. Как и другие сервисы хостинга, поставщик инфраструктуры может автоматически обрабатывать техническую информацию, связанную с обращениями к сайту, например IP-адрес, тип браузера, дату и время запроса и иные стандартные технические данные, в соответствии со своей политикой конфиденциальности.

4. Сторонние сайты

dokkino.com содержит ссылки на сторонние сервисы, включая YouTube и музыкальные платформы. После перехода на сторонний сайт обработка данных регулируется правилами и политикой конфиденциальности этого сервиса.

5. Платежи и поддержка проекта

На данный момент dokkino.com не принимает платежи непосредственно на сайте. Если в будущем будет подключён сторонний сервис для добровольной поддержки проекта, эта Политика будет обновлена до или одновременно с запуском такого функционала.

6. Изменения Политики

Политика может обновляться при добавлении новых функций сайта, аналитики, форм обратной связи, платёжных сервисов или иных инструментов обработки данных.

7. Контакт

По вопросам конфиденциальности можно связаться с нами через официальный контакт, указанный на сайте или на официальных страницах проекта.

Privacy Policy

This Policy describes the handling of information when you visit dokkino.com.

1. Information the website currently asks you to provide

The current version of dokkino.com does not include user registration, user accounts, payment forms, or forms through which a visitor intentionally provides a name, email address or payment information directly to the website owner.

2. Language preference

The website uses browser local storage (localStorage) to remember the selected interface language — Russian or English. This preference is stored in the user's browser and is used only to improve the browsing experience.

3. Technical data and hosting

The website is hosted using GitHub Pages. Like other hosting services, the infrastructure provider may automatically process technical information associated with requests to the website, such as an IP address, browser type, request date and time and other standard technical data, in accordance with its own privacy policy.

4. Third-party websites

dokkino.com contains links to third-party services, including YouTube and music platforms. Once you follow a link to a third-party website, data processing is governed by that service's own terms and privacy policy.

5. Payments and project support

dokkino.com does not currently accept payments directly on the website. If a third-party service for voluntary project support is added in the future, this Policy will be updated before or at the time that functionality is launched.

6. Changes to this Policy

This Policy may be updated when new website features, analytics, contact forms, payment services or other data-processing tools are added.

7. Contact

For privacy-related questions, please contact us through an official contact method listed on the website or on the project's official pages.
